## Rule: only fields available for every season
Clean data holds only fields that are filled for **every season, 1992-93 onwards**. There are no partly-empty columns, and the script fails if any output value is missing. So the following are **left out** even though some raw sources have them:

| Left out | Only available in |
|---|---|
| Matchweek | every season except 2023-24, 2024-25 and 2025-26 after matchweek 3 |
| Half-time score/result, shots, shots on target, corners, fouls, yellow/red cards | 2000-01 to 2025-26 (`epl-00-25`, `2425.csv`, `2526.csv`) |
| Kick-off time, referee | 2024-25 and 2025-26 (`2425.csv`, `2526.csv`) |
| Betting odds | 2024-25 and 2025-26 (`2425.csv`, `2526.csv`) |
| xG, possession, attendance, formations, captains | 2025-26 matchweeks 1–3 (`epl-25-26`) |
| Squad season stats (`team_season_stats.csv`) | 2025-26 snapshot only |

These are still in `raw_data/` for any analysis limited to the seasons that have them.

## Conventions (all files)
- **Column names** are `snake_case`. Home and away pairs use the `home_` / `away_` prefix.
- **`season`** is written `"YYYY-YY"` (`"2003-04"`), which sorts correctly as text. `season_start_year` is the same season as an integer (`2003`).
- **`date`** is ISO `YYYY-MM-DD`. `day_of_week` is `Mon`…`Sun`.
- **Teams** use one canonical name everywhere (`Manchester United`, `Nottingham Forest`), plus a 3-letter `team_code` (`MUN`, `NFO`). The display short name is in `teams.csv`.
- **`result`** is `H`, `D` or `A` from the home side's point of view, derived from the goals.

## Files

### `matches.csv`: one row per played match, 1992-93 to 2025-26
| Column | Notes |
|---|---|
| `match_id` | `season_HOME_AWAY`, e.g. `2003-04_ARS_TOT`. Unique. |
| `season`, `season_start_year` | |
| `date`, `day_of_week` | |
| `home_team`, `away_team`, `home_team_code`, `away_team_code` | Canonical names and codes |
| `home_goals`, `away_goals` | Full-time score |
| `result` | `H` / `D` / `A` |
| `sources` | `;`-separated raw datasets the row came from (dataset folders, or the file name for `2425.csv` / `2526.csv`) |

**Every season is complete:** 462 matches in the 22-team seasons up to 1994-95, 380 after. 13,166 matches in total.

### `teams.csv`: one row per club
`team`, `short_name`, `team_code`, `first_season`, `last_season`, `seasons_in_data`.

### `team_aliases.csv`: raw name → canonical team
`source`, `raw_name`, `team`, `differs_from_canonical`. Every raw spelling found in each source.

## How sources were merged
1. **Team names** are mapped to canonical names through `TEAMS` in the script. The script stops with an error if a raw name isn't mapped.
2. **1992-93 to 2022-23 matches** come from `epl-92-23`, which is complete. `epl-00-25` fills in its overlap and supplies 2023-24 and 2024-25. Scores agree on every one of the 8,650 overlapping matches (the script checks this).
3. **Dates** come from `epl-00-25` when the two disagree. There were 4 conflicts, all in 2001-02, and each was checked against ESPN and Wikipedia; `epl-00-25` was correct every time.
4. **2025-26** matchweeks 1–3 come from `epl-25-26/team_match_stats.csv`, played matches only, one row per match.
5. **The football-data.co.uk season files fill the rest.** `2425.csv` adds the last 30 matches of 2024-25 and `2526.csv` adds the 350 matches of 2025-26 after matchweek 3. Where they overlap an earlier source (350 matches in 2024-25, 30 in 2025-26), the script checks that scores and dates agree; they agree on all of them, and the file name is added to the row's `sources`.
